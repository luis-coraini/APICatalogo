# API de Mercado - ASP.NET Core

Este é um projeto de estudo desenvolvido durante um curso de ASP.NET Core. Trata-se de uma API REST para controle de um pequeno mercado, com funcionalidades básicas de CRUD (Create, Read, Update, Delete) para **Categorias** e **Produtos**.

## Finalidade

Este projeto tem como objetivo o aprendizado e prática de conceitos fundamentais de desenvolvimento de APIs com ASP.NET Core, Entity Framework Core, boas práticas de organização de código e configuração de ambiente.

## Funcionalidades

- Listar produtos e categorias  
- Adicionar novos produtos e categorias  
- Editar produtos e categorias existentes  
- Excluir produtos e categorias  
- Obter detalhes de um produto ou categoria pelo ID
- Obter todos produtos de uma categoria

## Tecnologias Utilizadas

- ASP.NET Core  
- Entity Framework Core  
- MySql 
- Scalar para documentação da API

## Para rodar o projeto
- Configure o arquivo `appsettings.json`, alterando o campo "DefaultConnection" com os seus dados
- Execute as migrations
